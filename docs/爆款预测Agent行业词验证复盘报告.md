# 爆款预测 Agent 行业词预测效果验证复盘报告

会议讨论稿  
角色视角：AI 产品经理  
数据口径：行业词输入后的 3 个预测选题，按 6h / 12h / 24h / 48h 追踪真实平台新增相似作品表现

---

## 1. 一句话结论

本轮验证说明，爆款预测 Agent 已经具备“行业词输入后，稳定发现后续可跟进内容机会”的能力：10 个行业赛道、30 个预测选题、120 个时间点验证中，几乎所有预测都能在预测后找到真实相似作品，阶段性 50 分准确率目标基本达成。

但这还不能直接等同于“用户照着拍一定爆”。当前更准确的产品定位应该是：

> 爆款预测 Agent 现阶段可以作为“机会发现和切口判断工具”，帮助用户判断某个行业方向是否正在形成内容机会；下一阶段需要继续验证“用户采纳后真实发布的命中率”。

---

## 2. 管理层摘要

### 2.1 本轮验证回答的问题

本轮不是验证 UI 是否好看，也不是验证脚本生成质量，而是验证一个更底层的问题：

> 用户只输入一个行业词时，Agent 给出的 3 个明确选题，未来 6-48 小时内市场上是否真的出现了相似作品，以及这些作品的数据是否足够支撑“这个机会值得跟”。

### 2.2 核心结果

| 指标 | 结果 | 解释 |
| --- | ---: | --- |
| 行业赛道数 | 10 个 | 包含 AI 工具、健身减脂、母婴育儿、职场效率、小红书美妆、家居收纳、本地生活探店、数码科技、宠物萌宠、餐饮加盟 |
| 预测选题数 | 30 个 | 每个行业词输出 3 个明确选题 |
| 验证时间点 | 120 个 | 30 个选题 × 6h / 12h / 24h / 48h |
| 可评估覆盖率 | 100% | 每个验证点都能找到可计算的真实样本 |
| 50 分准确率达标 | 119 / 120，约 99% | 阶段性目标达成 |
| 严格准确率达标 | 55 / 120，约 46% | 以 80 分为门槛，仍有明显优化空间 |
| 平均预测分 | 87 | Agent 对机会整体偏积极 |
| 平均真实表现分 | 66 | 市场真实作品表现中等偏上 |
| 平均准确率 | 77 | 预测分和真实样本表现之间存在一定校准差距 |

### 2.3 最重要的产品判断

1. Agent 的“方向发现能力”已经可用。
2. Agent 的“强爆款精确命中能力”还不够稳定。
3. 24 小时内是当前最值得关注的验证窗口。
4. 48 小时后仍能找到样本，但优质样本比例开始下降。
5. 不同赛道差异很大，不能用一套通用算法解决所有行业。
6. 产品上不建议简单把分数整体打低，而应该增加“证据强度、时间窗口、赛道可信度、相似样本质量”这些辅助判断。

## 3. 验证背景

爆款预测 Agent 的核心产品承诺不是“生成一个好看的选题标题”，而是：

> 在用户还没有明确内容方向时，提前判断某个行业里接下来可能出现的内容机会，并给出可跟进的 3 个选题方向。

因此，效果验证不能只看模型输出是否像样，而要看三个问题：

1. 预测之后，市场上是否真的出现相似作品？
2. 这些相似作品的数据是否足够好？
3. Agent 判断的高分机会，是否真的比普通方向更容易出现有效内容？

本轮验证选择“行业词”作为输入，是因为行业词比具体热点更难。用户输入“AI 工具”“健身减脂”“本地生活探店”这类泛行业词时，Agent 需要自己完成：

1. 行业理解
2. 热点识别
3. 内容供给判断
4. 选题拆解
5. 后续样本匹配

如果行业词输入也能做到 50% 以上准确率，说明产品具备基础泛化能力。

## 4. 验证设计

### 4.1 输入方式

本轮使用 10 个行业赛道词作为输入，每个行业词让 Agent 输出 3 个明确选题。

10 个行业赛道：

| 赛道 | 选择原因 |
| --- | --- |
| AI 工具 | 产品重点赛道，必须纳入 |
| 健身减脂 | 内容量大、同质化高，适合测试筛选能力 |
| 母婴育儿 | 用户需求明确，适合测试实用型内容判断 |
| 职场效率 | 与 AI 工具相邻，适合测试办公场景机会 |
| 小红书美妆 | 平台种草属性强，适合测试图文/短视频趋势 |
| 家居收纳 | 长尾需求强，适合测试生活方式内容机会 |
| 本地生活探店 | 强地域和强场景，适合测试相似度匹配能力 |
| 数码科技 | 热点变化快，适合测试趋势跟进能力 |
| 宠物萌宠 | 情绪内容强，适合测试非知识型赛道 |
| 餐饮加盟 | 商业化强、噪声高，适合测试低质招商内容过滤 |

### 4.2 输出结构

每个行业词输出 3 个选题，因此一共得到 30 个预测选题。

每个选题至少包含：

1. 预测标题或选题方向
2. 推荐切口
3. 爆发指数 / 预测分
4. 参考关键词
5. 后续相似作品搜索词

### 4.3 验证时间点

每个预测选题在 4 个时间点进行回查：

| 时间点 | 目的 |
| --- | --- |
| 6 小时 | 看是否有快速跟进样本 |
| 12 小时 | 看早期趋势是否成形 |
| 24 小时 | 看是否进入主窗口 |
| 48 小时 | 看趋势是否仍然有效，或已经衰减 |

### 4.4 搜索方式

不是直接拿完整标题硬搜，而是把 Agent 输出拆成行业词、核心对象、场景词、动作词、痛点词，再组合搜索。

这样做的原因是：短视频平台的真实标题不会完全复刻 Agent 生成的标题。如果只用完整标题搜索，会漏掉大量“同方向但不同表达”的真实作品。

例如：

```text
预测选题：减脂期敢吃站点披萨？这一顿真的超疯狂

不能只搜：
减脂期敢吃站点披萨这一顿真的超疯狂

应该拆成：
减脂 / 站点披萨 / 减脂餐 / 低卡 / 碳水 / 反常识 / 真实测评
```

### 4.5 数据来源

本轮数据来自项目内行业词验证脚本生成的结果文件：

```text
evals/industry-accuracy/reports/industry_eval_2026-05-09T00-36-19-685Z_5956e535.detail.json
evals/industry-accuracy/reports/industry_eval_2026-05-09T00-36-19-685Z_5956e535.detail.csv
```

预测批次创建时间：

```text
2026-05-09 08:36，UTC+8
```

详细报告生成时间：

```text
2026-05-11 11:00，UTC+8
```

### 4.6 真实样本定义

本轮只统计预测后出现的作品。

为了避免把预测前已经存在的作品算进去，复盘时采用更严格口径：

```text
真实样本发布时间 >= 预测创建时间 + 5 分钟
```

这意味着：

1. 预测前已有作品不计入新增样本。
2. 预测刚生成前后的平台时间边界样本不轻易计入。
3. 更接近“预测之后市场是否真的出现相似内容”的验证目标。

## 5. 指标口径

### 5.1 predictedScore

Agent 输出的预测分，来自结果中的选题分数或机会分。

它代表：

```text
Agent 对这个选题机会的主观预测强度
```

它不应该被理解为：

```text
这条内容真实发布后一定能拿到多少播放量
```

### 5.2 actualScore

真实样本表现分，由平台真实作品互动数据派生。

本批次 TikHub 返回的样本中，播放量字段大部分不可用或为 0，因此本轮没有用播放量作为核心判断，而是使用以下互动数据：

1. 点赞
2. 评论
3. 收藏
4. 分享
5. 同批样本内排序

因此，本轮 actualScore 更准确地说是：

```text
真实相似作品的互动表现分
```

不是：

```text
真实播放量表现分
```

### 5.3 accuracy

当前准确率计算方式：

```text
accuracy = 100 - abs(predictedScore - actualScore)
```

示例：

| predictedScore | actualScore | accuracy |
| ---: | ---: | ---: |
| 90 | 80 | 90 |
| 88 | 65 | 77 |
| 92 | 46 | 54 |

这个指标适合看“分数是否大体接近”，但不适合单独判断商业价值。

原因是：

```text
预测 92，真实 46，accuracy 仍然有 54，能过 50 分门槛，但从产品体验看这仍然是明显高估。
```

所以，本轮同时引入了更严格的业务指标。

### 5.4 宽松达标

```text
accuracy >= 50
```

这是当前阶段目标：只要用户输入行业词，Agent 至少要有 50% 以上的预测可信度。

### 5.5 严格达标

```text
accuracy >= 80
```

这是更接近成熟产品要求的指标。

### 5.6 强相关优质样本

为了更接近真实业务价值，复盘中额外统计：

```text
相似度 >= 60 且 actualScore >= 70
```

这类样本代表：

1. 方向确实相似
2. 不是泛热点乱匹配
3. 数据表现也不错

这个指标比 accuracy 更严格，也更接近“用户会不会觉得这个预测有价值”。

## 6. 总体结果

### 6.1 总体数据

| 指标 | 结果 |
| --- | ---: |
| 行业数 | 10 |
| 预测选题数 | 30 |
| 验证点数 | 120 |
| 可评估验证点 | 120 |
| 可评估覆盖率 | 100% |
| 宽松准确率达标数 | 119 |
| 宽松准确率达标率 | 99% |
| 严格准确率达标数 | 55 |
| 严格准确率达标率 | 46% |
| 平均准确率 | 77 |
| 平均预测分 | 87 |
| 平均真实分 | 66 |

### 6.2 产品解释

这组数据说明：

1. Agent 不是随机给选题。预测之后，市场中确实能找到大量相似作品。
2. 方向性判断有基础可信度。99% 的验证点达到 50 分准确率。
3. 但高分机会的精确性还不够。严格 80 分准确率只有 46%。
4. 当前预测分整体偏乐观。平均预测分 87，平均真实分 66，中间有约 21 分差距。

### 6.3 不能过度解读的地方

这轮验证不能直接证明：

1. 用户发布后一定能爆。
2. Agent 能准确预测播放量。
3. 每个赛道都已经稳定可商业化。
4. 高分选题都一定值得付费用户立即执行。

它能证明的是：

1. Agent 对行业机会的方向判断有效。
2. 预测后真实市场中会出现相似内容。
3. 部分赛道已经能形成较强证据链。
4. 需要进一步把“预测分”和“证据强度”分开表达。

## 7. 分时间点结果

### 7.1 四个时间点对比

| 时间点 | 样本数 | 宽松达标率 | 严格达标率 | 平均准确率 | 平均真实分 | actualScore >= 70 | actualScore >= 80 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 6h | 30 | 100% | 40% | 75.0 | 64.0 | 33% | 7% |
| 12h | 30 | 100% | 43% | 76.8 | 65.8 | 40% | 10% |
| 24h | 30 | 100% | 50% | 80.1 | 68.3 | 47% | 23% |
| 48h | 30 | 97% | 50% | 77.8 | 66.6 | 47% | 23% |

### 7.2 时间窗口判断

从预测准确率看，24 小时是当前最好的窗口：

1. 平均准确率最高：80.1
2. 严格达标率达到 50%
3. 高分真实样本比例提升到 47%
4. 80 分以上真实样本比例从 6h 的 7% 提升到 24h 的 23%

48 小时仍然有效，但已经出现衰减信号：

1. 宽松达标率从 100% 降到 97%
2. 平均准确率从 80.1 降到 77.8
3. 平均真实分从 68.3 降到 66.6

### 7.3 产品建议

结果页不要只展示一个固定爆发指数，应增加时间窗口解释：

| 发布时间窗口 | 产品表达 |
| --- | --- |
| 0-12 小时 | 强建议跟进，适合快速测试 |
| 12-24 小时 | 仍在主窗口，适合正式发布 |
| 24-36 小时 | 建议观察样本质量后再投入 |
| 36 小时后 | 需要复查，不建议只凭原预测分行动 |

重点是：主分数不一定要整体调低，但需要让用户知道窗口期在变化。

## 8. 按真实作品发布时间分析

为了判断真实作品是在什么时候开始出现表现，我们对预测后新增真实作品按发布时间分桶。

### 8.1 48 小时内真实作品表现

| 发布时间 | 作品数 | 平均真实分 | 中位真实分 | actualScore >= 70 | actualScore >= 80 | 强相关优质样本率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0-3h | 12 | 75.9 | 81 | 58% | 58% | 42% |
| 3-6h | 10 | 72.6 | 70 | 50% | 40% | 20% |
| 6-12h | 37 | 76.3 | 80 | 70% | 54% | 41% |
| 12-24h | 12 | 69.1 | 62 | 42% | 42% | 17% |
| 24-36h | 91 | 65.2 | 65 | 46% | 26% | 20% |
| 36-48h | 32 | 52.9 | 52 | 13% | 3% | 6% |
| 48-60h | 21 | 43.9 | 39 | 0% | 0% | 0% |

### 8.2 关键发现

1. 最强窗口不是 48 小时末尾，而是 6-12 小时。
2. 0-3 小时内也有强样本，但数量少，波动大。
3. 24-36 小时仍有大量作品出现，但质量开始分化。
4. 36 小时后，真实作品质量明显下降。
5. 48 小时后，几乎不能再把原预测当作强机会。

### 8.3 对产品的影响

结果页应该从“静态预测”升级为“带时间衰减的预测”。

建议表达方式：

```text
爆发指数：92
当前窗口：主窗口 / 衰减中 / 需要复查
证据状态：已有高相似样本 / 只有中等样本 / 样本不足
行动建议：今天拍 / 先小成本测试 / 换切口
```

这样可以在不打击用户体验的情况下，提高判断可信度。

| AI 工具 | 100% | 42% | 79.3 | 66.6 | 92% | 72.7 |
| 小红书美妆 | 100% | 33% | 76.5 | 64.8 | 75% | 52.4 |
| 家居收纳 | 100% | 33% | 76.0 | 61.5 | 50% | 64.2 |

| 餐饮加盟 | 100% | 8% | 65.9 | 53.3 | 58% | 52.8 |

### 9.2 强势赛道

#### 数码科技

表现：

1. 严格达标率 92%
2. 平均真实分 78.8
3. 平均最高相似度 71.3
4. 48 小时强相关优质样本率 45%

判断：

数码科技适合预测 Agent，因为该赛道具备几个特征：

1. 热点对象明确，例如 iPhone、设备、系统、工具。
2. 用户搜索意图清晰。
3. 真实作品标题和内容表达相对标准化。
4. 新作品出现速度快。

产品建议：

数码科技可以作为早期标杆赛道，用来展示 Agent 的预测能力。

#### 宠物萌宠

表现：

1. 高中质量样本率 100%
2. 严格达标率 75%
3. 平均真实分 76.1

判断：

宠物赛道虽然情绪化，但内容模式稳定，例如“宠物反应”“主人互动”“萌宠日常”。Agent 比较容易预测出后续会出现的内容类型。

产品建议：

宠物赛道可以继续保留，但结果页要少讲“理性趋势”，多讲“情绪钩子”和“可复制情境”。

#### 本地生活探店

表现：

1. 平均准确率 85.6
2. 严格达标率 75%
3. 但宽松达标率只有 92%，出现 1 个明显失败样本

判断：

本地生活容易出现数据好的真实作品，但相似度判断容易受地域、店型、价格、人群影响。

产品建议：

本地生活需要在搜索和匹配时加入：

1. 城市
2. 店型
3. 人均价格
4. 消费场景
5. 是否老店 / 新店 / 网红店

否则可能把“早餐老店”和“美食合集”误判为同类机会。

### 9.3 中等赛道

#### AI 工具

表现：

1. 宽松达标率 100%
2. 平均准确率 79.3
3. 平均真实分 66.6
4. 平均最高相似度 72.7

判断：

AI 工具方向匹配能力较好，但真实表现分不算特别高。原因可能是：

1. AI 工具内容竞争强。
2. 大号和资讯号反应更快。
3. 中腰部账号如果只做资讯转述，容易被压制。
4. 真正能爆的通常是“具体使用场景”，不是“工具新闻”。

产品建议：

AI 工具赛道不能只推荐“某工具更新”，要强制转成：

1. 工作流
2. 场景教程
3. 对比测试
4. 普通人可操作方法

这是结果页之前强调“切口而不是标题”的原因。

#### 母婴育儿

表现：

1. 平均准确率 80.8
2. 平均真实分 69.8
3. 48 小时强相关优质样本率 57%

判断：

母婴赛道真实用户需求强，尤其是育儿经验、亲子沟通、孩子习惯、家庭教育这类方向，后续真实样本质量较好。

风险：

不能进入医疗、诊断、功效承诺等高风险表达。

产品建议：

母婴赛道应偏“经验分享”和“情绪共鸣”，不做强专业结论。

### 9.4 需要重点优化赛道

#### 餐饮加盟

表现：

1. 严格达标率只有 8%
2. 平均真实分 53.3
3. 48 小时强相关优质样本率 0%
4. 48 小时真实样本中位互动加权仅 5.5

判断：

餐饮加盟是本轮最需要修的赛道。

主要问题不是找不到内容，而是内容噪声太大：

1. 招商广告多。
2. 低质引流内容多。
3. 标题相似但内容价值低。
4. “加盟项目推荐”和“真实探店/经营经验”混在一起。
5. 平台上大量内容是获客广告，不是真正的自然爆款。

产品建议：

餐饮加盟要先做样本质量过滤，再做预测。

建议加入过滤规则：

1. 过滤“加盟”“招商”“0 元开店”“总部扶持”“留资”等强广告词。
2. 降低纯招商账号权重。
3. 优先真实门店经营、成本拆解、老板经验、选址避坑类内容。
4. 将“餐饮加盟”拆成两个不同产品赛道：
   - 餐饮经营经验
   - 加盟项目广告
5. 对后者默认降低证据强度，不作为强推荐机会。

#### 健身减脂

表现：

1. 平均准确率 69.1
2. 平均真实分 57.4
3. 48 小时强相关优质样本率 10%

判断：

健身减脂问题在于同质化太严重。

常见噪声：

1. 减脂餐
2. 跑步跳绳
3. 燃脂动作
4. 反常识标题
5. 低质量搬运

Agent 容易识别到“有热度”，但不容易判断哪个内容真的有差异化。

产品建议：

健身减脂赛道要更强调：

1. 真实测评
2. 过程记录
3. 体重/围度变化
4. 饮食选择理由
5. 可验证的个人经验

不应该高推泛化标题，例如：

```text
别再死磕跑步跳绳，4 个动作睡觉也能燃脂
```

这类内容虽然容易吸引点击，但真实样本质量并不稳定，且容易进入夸张承诺。

## 13. 为什么 50% 准确率达标，但仍然不能说效果已经完全过关

这是本轮最需要在会上讲清楚的地方。

### 13.1 50% 准确率达标代表什么

它代表：

```text
预测分和真实样本表现不是完全脱节，方向判断具备基本可信度。
```

### 13.2 50% 准确率不代表什么

它不代表：

```text
每个高分选题都能产生强爆款。
```

例如：

```text
predictedScore = 92
actualScore = 46
accuracy = 54
```

这个结果按 50 分门槛是达标的，但从用户体验看，实际是高估。

### 13.3 下一阶段应该看什么

下一阶段需要把验证指标分成两层：

1. 机会方向是否成立
2. 是否出现强相关优质样本

建议新增正式业务指标：

```text
Strong Relevant Hit Rate
= 预测后真实作品中，相似度 >= 60 且 actualScore >= 70 的比例
```

当前 48 小时该指标约为：

```text
20%
```

这才是更接近“用户会觉得有用”的指标。

## 14. 当前产品应该怎么表达预测分

### 14.1 不建议把所有分数直接校准变低

原因：

1. 用户看到低分会直接失去使用动力。
2. 预测分本质上是机会判断，不是播放量承诺。
3. 当前核心问题不是分数全部虚高，而是证据强度没有表达出来。

### 14.2 建议增加辅助解释层

推荐保留主分数，但增加以下字段：

| 字段 | 作用 |
| --- | --- |
| 时间窗口 | 告诉用户现在是主窗口还是衰减期 |
| 证据强度 | 告诉用户真实样本是否足够强 |
| 相似样本质量 | 告诉用户是不是只有泛样本 |
| 赛道可信度 | 告诉用户该赛道历史验证是否稳定 |
| 执行建议 | 告诉用户该强跟、轻测还是放弃 |

示例：

```text
爆发指数：90
当前窗口：主窗口
证据强度：中
真实样本：已有 4 条高相似样本，其中 2 条互动表现较强
行动建议：建议今天小成本测试，不建议直接重投入
```

这样既不破坏用户体验，也不会让预测显得过度承诺。

## 15. 产品优化建议

### 15.1 加入时间衰减

依据：

1. 6-12 小时样本表现最好。
2. 24 小时仍是主窗口。
3. 36 小时后真实样本质量明显下降。
4. 48 小时后高质量样本几乎消失。

建议：

结果页保留爆发指数，但增加窗口状态：

| 时间状态 | 展示建议 |
| --- | --- |
| 0-12h | 强建议跟进 |
| 12-24h | 主窗口内 |
| 24-36h | 观察后再投入 |
| 36h+ | 建议复查 |

### 15.2 重点修餐饮加盟

问题：

1. 招商广告污染严重。
2. 强相关优质样本率为 0。
3. 平均真实分最低。

动作：

1. 加入招商广告过滤词。
2. 区分餐饮经营和餐饮加盟。
3. 降低留资型内容权重。
4. 优先真实经营、门店成本、选址经验。

### 15.3 重点修健身减脂

问题：

1. 同质化强。
2. 真实样本表现弱。
3. 标题党容易干扰。

动作：

1. 加入“真实过程”权重。
2. 加入“个人体验”权重。
3. 降低夸张功效承诺内容权重。
4. 强制输出更具体场景，而不是泛减脂标题。

### 15.4 AI 工具赛道继续保留为重点，但必须强调场景化

AI 工具方向可用，但不能走资讯搬运。

建议 Agent 输出时优先选择：

1. 办公效率场景
2. 真实工具演示
3. 普通人可复制工作流
4. 对比测试
5. 使用前后效果

不要高推：

1. 工具新闻合集
2. 模型更新解读
3. 泛 AI 趋势标题

### 15.5 增加赛道级可信度

同样是 90 分，不同赛道可信度不同。

建议在前端和报告中增加：

```text
赛道历史验证：稳定 / 中等 / 待观察
```

当前初步分层：

| 级别 | 赛道 |
| --- | --- |
| 稳定 | 数码科技、宠物萌宠、本地生活探店、母婴育儿 |
| 中等 | AI 工具、小红书美妆、家居收纳、职场效率 |
| 待优化 | 健身减脂、餐饮加盟 |

## 16. 对结果页的影响

本轮验证进一步确认，结果页的定位应该是：

```text
预测决策页 + 下一步生成入口
```

不是：

```text
完整脚本 / 标题 / 封面交付页
```

原因：

1. 当前最有价值的是机会判断，不是一次性给素材。
2. 用户最先需要知道是否值得做。
3. 真实数据存在时间窗口和赛道差异，必须先解释判断边界。
4. 如果在结果页直接给完整脚本，会弱化“确认机会后继续生成”的产品链路。

结果页应该优先展示：

1. 是否值得跟
2. 为什么现在值得跟
3. 哪类账号适合
4. 推荐切口
5. 真实样本证据
6. 风险和放弃条件
7. 下一步生成入口

## 17. 管理层可能追问与回答

### Q1：这些数据是不是 Agent 输出之后才采集的？有没有拿预测前的旧样本充数？

答：

本轮复盘采用严格口径，只统计预测创建时间 5 分钟之后发布的作品。

预测批次创建时间是：

```text
2026-05-09 08:36，UTC+8
```

复盘口径为：

```text
作品发布时间 >= 2026-05-09 08:41，UTC+8
```

因此，预测前已有作品不计入新增样本。

### Q2：为什么很多样本没有播放量？那 actualScore 可靠吗？

答：

TikHub 本批次返回的样本中，播放量字段大部分不可用或为 0，所以本轮没有把播放量作为核心指标。

actualScore 基于点赞、评论、收藏、分享和样本内排序计算。

这意味着本轮验证的是：

```text
真实相似作品的互动表现
```

不是：

```text
真实播放量表现
```

这是一个明确限制。下一阶段需要补齐播放量或完播率数据，才能做更强的商业命中率判断。

### Q3：99% 准确率听起来很高，为什么还说不能过度乐观？

答：

99% 是按 50 分阶段性门槛计算的宽松准确率。它说明方向判断基本成立。

但严格 80 分准确率只有 46%，48 小时强相关优质样本率约 20%。

所以更准确的判断是：

```text
Agent 已经能发现机会，但还不能稳定保证强爆款。
```

### Q4：如果平均预测分 87，平均真实分 66，是不是模型虚高？

答：

存在偏乐观问题，但不建议简单把所有分数压低。

因为预测分表达的是“机会强度”，不是“真实表现承诺”。

更好的做法是：

1. 保留主分数，维持用户行动感。
2. 增加证据强度，降低误导。
3. 增加时间窗口，提醒机会衰减。
4. 增加赛道可信度，解释不同赛道差异。

### Q5：哪几个赛道最值得继续投入？

答：

当前最值得继续投入：

1. 数码科技
2. 宠物萌宠
3. 母婴育儿
4. 本地生活探店
5. AI 工具

其中 AI 工具是产品战略赛道，必须继续做，但要从资讯解读转成场景工作流。

### Q6：哪几个赛道最需要修？

答：

优先修：

1. 餐饮加盟
2. 健身减脂

餐饮加盟的问题是招商广告污染。  
健身减脂的问题是同质化和标题党污染。

### Q7：这轮能不能证明用户付费价值？

答：

只能证明一部分。

它证明了：

1. Agent 可以发现后续真实市场机会。
2. 部分赛道可以产生较强证据。
3. 行业词输入不是无效输入。

它还不能证明：

1. 用户采纳后一定爆。
2. 用户愿意为单次预测长期付费。
3. 预测结果能稳定提升账号数据。

下一阶段必须做用户采纳链路验证：

```text
预测结果 -> 用户选择切口 -> 生成内容 -> 用户发布链接 -> 48h / 72h / 7d 表现追踪
```

### Q8：为什么不直接用真实作品表现训练或校准分数？

答：

短期不建议直接校准主分数。

原因：

1. 样本量还不够大。
2. 不同赛道差异明显。
3. 当前 actualScore 缺少播放量。
4. 如果直接压低分数，会削弱用户行动意愿。

更合理的顺序是：

1. 先加证据强度。
2. 再加时间衰减。
3. 再加赛道级修正。
4. 最后等用户发布数据回流后，再做真正的分数校准。

### Q9：为什么 6-12 小时数据最好？

答：

推测原因：

1. 预测时热点已经开始萌芽。
2. 创作者会在几个小时内快速跟进。
3. 早期优质内容更容易集中出现。
4. 到 36 小时后，更多是低质量跟风、搬运和长尾内容。

所以产品上应鼓励用户在 24 小时内完成动作，36 小时后提示复查。

### Q10：这个系统最终应该卖什么？

答：

不是卖“AI 写标题”，而是卖：

```text
内容机会判断能力
```

用户真正付费的理由应该是：

1. 帮我判断这个方向值不值得做。
2. 帮我避开已经同质化的方向。
3. 帮我找到中腰部账号能切入的位置。
4. 帮我在窗口期内快速生成下一步内容。

## 20. 最终判断

本轮验证的结论可以概括为：

> 爆款预测 Agent 已经过了“不是随机猜”的阶段，行业词输入后能稳定找到预测后出现的真实相似作品；但还没有过“稳定预测强爆款”的阶段。当前最正确的产品打法，是把它包装成创作者的内容机会判断工具，而不是绝对爆款承诺工具。

短期最该做的不是把 UI 做得更花，也不是简单压低分数，而是：

1. 把预测证据讲清楚。
2. 把时间窗口讲清楚。
3. 把赛道差异讲清楚。
4. 把高噪声赛道修掉。
5. 把用户发布后的真实结果接回来。

只要下一轮能把 24h / 48h 强相关优质样本率从当前约 20% 提升到 25%-30%，并且把餐饮加盟、健身减脂两个弱赛道修上来，产品就可以从“可演示”进一步走向“可收费验证”。
