## 一句话定义

**输入一个赛道关键词 / 一条对标视频链接 / 一个账号链接 —— 30 秒内,
给出 3 个今天就能开拍的爆款选题,每个选题都附带具体对标样本和爆发指数。**

(取自 [docs/PRD-v1.md](../PRD-v1.md) §1)

每个限定都不是凑字数:

| 限定 | 含义 |
|------|------|
| **30 秒内** | 慢于这个数 = "我自己刷热搜也是这个时间",AI 没价值 |
| **3 个选题** | 决策成本最低的"短列表"——多了挑花眼,少了显得敷衍 |
| **对标样本** | 区别于通用 AI 的"凭印象编"——每条结论都来自真实采集到的近期内容 |
| **爆发指数** | 对外展示的机会评分标签;v1.0 主结果页以对应卡片返回分值为准,不把 7 维机会分当成唯一真值 |

## 目标用户

### 核心用户(v1.0 唯一聚焦)

**抖音 / 小红书的中腰部自媒体创作者**(粉丝 1k–50k)。
他们的痛点不是"不会拍",而是"不知道现在该拍什么"。

| 维度 | 描述 | 来源 |
|------|------|------|
| **粉丝规模** | 100 – 50,000 | docs/business/产品定位.md |
| **平台** | 主战场抖音 / 小红书 / 快手中的 1 个,副战场 1 个 | 同上 |
| **更新频率** | 每周更 2–7 条 | 同上 |
| **赛道** | 美食、母婴、宠物、知识、时尚、情感、低门槛 vlog | 同上 |
| **付费意愿** | 月 ¥30–200 | 同上 |

### 次级用户

- **MCN 实习生 / 助理**:帮创作者整理选题
- **自媒体小工作室(2–5 人)**:选题决策需团队协作

### 明确不服务(v1.0)

(取自 [docs/PRD-v1.md](../PRD-v1.md) §2)

- ❌ MCN 投放运营 —— 要的是规模化数据看板,不是单选题
- ❌ 知识博主写长文 —— 爆款逻辑不一样
- ❌ 品牌投放方 —— 要的是种草数据
- ❌ 100 万粉以上大号 —— 已有专业团队 + 自有数据
- ❌ 真·新人(0 粉)—— "对比 TA 平时水平"对他们失效
- ❌ 严肃媒体 —— 选题逻辑是"事件 + 责任",不是爆款数据

## 核心痛点

| 痛点 | 用户原话 / 现状 | 我们怎么解 |
|------|-------------|-----------|
| **每天刷热搜决策选题** | 早上花 30 分钟刷抖音 + 30 分钟刷小红书,累计 1 小时 | 输入关键词 / 链接,30 秒内 3 张选题卡 |
| **小账号绝对值永远不算成功** | 1 万赞=爆款 这一行业默认值 → 1k 粉创作者永远算输 | 用 TA 自己近 3 个月作品的前 25% 作参照 |
| **跨平台风向看不到** | 主刷自己平台,A 平台已火 / B 平台未起的迁移机会被错过 | 同步看抖音 / 小红书 / 快手三家最新爆款 |
| **通用 AI 凭印象编选题** | ChatGPT 不接平台真实数据,选题没有对标 | 每条选题都附"采集到的真实样本" |

## 核心价值

(取自 [docs/business/产品定位.md](../business/产品定位.md))

### 一句话

**"让你每天少花 30 分钟刷热搜,3 张选题卡告诉你今天该拍啥。"**

### 三条具体价值

1. **决策效率**:1 小时 → 1.5 分钟,**每天省 ~1 小时,一年 ≈ 45 个工作日**
2. **跨平台视野**:同步看 3 个平台 → 抓得到平台间迁移机会
3. **按 TA 自己规模衡量**:北极星指标定义为"达到 TA 自己近 3 个月作品前 25%"
   (见 [docs/business/指标体系.md](../business/指标体系.md))

### 差异化(右上象限)

| 类型 | 代表 | 我们比它强的地方 |
|------|------|-----------------|
| 平台自带创作中心 | 抖音创作者中心、小红书蒲公英 | 跨平台 + 主动给选题 |
| 第三方数据工具 | 新榜 / 飞瓜 / 千瓜 / 卡思 | AI 决策 + 小创作者价格(¥19–49 vs ¥500+) |
| 通用 AI | ChatGPT / 文心一言 + prompt | 基于真实平台数据 |
| 小工具 | 各种"灵感工具" | 数据深度 + AI 能力 + 体验 |

## 商业目标

### 收费模型(以代码为准:[server/routers/credits.ts](../../server/routers/credits.ts))

**计费单位:积分**。单次预测消耗 = 基础 20 积分 + 每多 1 个平台 +10 积分,
典型一次预测 30–50 积分。新用户注册赠送 60 积分(够 1–2 次完整预测)。

| 套餐 | 月付 | 连续包月 | 年付 | 含积分/月 |
|------|------|---------|------|---------|
| **Plus**(引流款) | ¥19 | ¥15 | ¥108(¥9/月) | 200 积分 |
| **Pro**(主营收) | ¥49 | ¥39 | ¥300(¥25/月) | 600 积分 |

积分包(单次按需购买):100 积分 ¥12 / 300 积分 ¥30 / 800 积分 ¥70 / 2000 积分 ¥150。

### 收入预期(简版,取自 [docs/business/产品定位.md](../business/产品定位.md))

| 假设 | 数值 |
|------|------|
| 上线半年付费用户 | 500(Plus 350 + Pro 150) |
| 月营收(半年) | ≈ ¥12,700 |
| 上线 1 年付费用户 | 2,500(Plus 1500 + Pro 1000) |
| 月营收(1 年) | ≈ ¥70,500 |
| 加权月毛利 / 用户 | ≈ ¥18 |
| 招客倍数(LTV/CAC) | ≈ 3.4 倍(刚过行业 3 倍健康线) |

**单次预测成本目标 ≤ ¥3**(数据源 ≈ ¥0.4–2 + AI ≈ ¥0.4–1)。

## 当前版本目标(v1.0)

(取自 [docs/PRD-v1.md](../PRD-v1.md) §4 / §6)

### Must(M1–M5)

| # | 项 | 验收标准 |
|---|---|---------|
| **M1** | 服务端到端可用 | manus.space 域名下,新用户从打开到拿到结果页 < 60 秒,无 502 / 不刷新 / 不卡登录 |
| **M2** | 3 张选题卡片 | 每次预测稳定输出 ≥ 3 张,含:标题 / 切入角度 / 爆发指数 / 对标样本 / 核心标签 |
| **M3** | 数据相关性 ≥ 80% | LLM 语义过滤后,按默认验收草案抽样 50 条选题卡;相关率 ≥ 80%(见 [DOMAIN_RULES.md](DOMAIN_RULES.md) §4.2) |
| **M4** | 一键生成脚本 | 点击"生成开拍脚本"必须跳到脚本编辑器并预填该选题上下文 |
| **M5** | 命中率可观测 | 默认复用内部受保护查询 / 后台页,能查看"预测分 vs 48 小时后真实表现"的最近样本与命中率 |

### 上线前必须的 5 个数

1. **进站可用率** ≥ 95%
2. **预测时长 P95** ≤ 30 秒
3. **选题点击转化** ≥ 30%
4. **预测命中率**(48h 后赛道点赞中位数提升 ≥ 30% 的样本占比) ≥ 40%
5. **NPS**(小样本 20 人) ≥ 30

> 任意一个不达标,v1.0 不上线。
