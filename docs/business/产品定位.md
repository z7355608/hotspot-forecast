# 产品定位

> 我们做的是什么、给谁、为什么愿意付钱、和别人有什么不同——
> 一份带证据和判断的产品定位说明。

---

## TL;DR(1 屏速览)

| 维度 | 一句话答案 |
|------|----------|
| **是什么** | 给粉丝量小到中等的短视频创作者,30 秒内出 3 条今天该拍的选题 |
| **给谁** | 抖音 / 小红书 / 快手上 100–50,000 粉,每周更 2–7 条的腰部以下创作者 |
| **凭什么** | 三家最新爆款数据 + 按 TA 自己平时水平评估,**绝对值小账号永远不算成功的问题被解决了** |
| **付费点** | Plus ¥19/月(200 积分) / Pro ¥49/月(600 积分);积分制,典型一次预测 30–50 积分 |
| **差异化** | 平台自有(只看一家)/ 第三方数据工具(给数据不给决策)/ 通用 AI(不接真实数据)三者都缺位的右上象限 |
| **回本** | 单次预测成本 ¥1.5–3;Plus 主拉新 / Pro 主营收;靠走量 + 年付锁住流失 |
| **最大风险** | 抖音 / 小红书自己下场做(中等概率,2 年内)→ 跨平台是核心护城河 |

---

## 一句话定义

**「为粉丝量小到中等的短视频创作者,30 秒内给出 3 条今天该拍的选题——
数据来自抖音/小红书/快手三家最新爆款,评判用的是 TA 自己平时表现的水平,
帮他们省掉每天刷热搜决策的时间。」**

每个限定都不是凑字数:

| 限定 | 不这么说会怎样 |
|------|--------------|
| **粉丝量小到中等的创作者** | 大号有专门团队 + 自有数据,不需要 AI 选题——产品对他们没用 |
| **30 秒内** | 慢于这个数 = "我自己刷热搜也是这个时间",AI 没价值;快了价值翻倍提升 |
| **三家最新数据** | 只看一家 = 平台自带的"创作者中心"已有,我们没有差异化 |
| **TA 自己平时水平** | 用绝对数(1 万赞才算爆)的话,小账号永远不算成功——产品对小账号没意义 |
| **省决策时间** | 不是"教你怎么拍",是"帮你决定拍什么"——这是切入点 |

## 谁是用户

### 主要用户

| 维度 | 描述 |
|------|------|
| **粉丝规模** | 100 – 50,000 |
| **平台** | 主战场抖音 / 小红书 / 快手中的 1 个,副战场 1 个 |
| **更新频率** | 每周更 2–7 条 |
| **赛道** | 美食、母婴、宠物、知识、时尚、情感、低门槛 vlog |
| **痛点(产品价值锚点)** | "今天 / 这周拍什么"——决策本身比拍摄更难 |
| **付费意愿** | 月 ¥30–200,愿为"省时间 + 提高命中率"付费 |
| **不愿付费的事** | 单纯"参考榜单"(平台已经免费给) |

### 次级用户

| 维度 | 描述 |
|------|------|
| **MCN 实习生 / 助理** | 帮创作者整理选题的中间角色 |
| **自媒体小工作室(2–5 人)** | 选题决策需要团队协作 |

### 不是用户(明确剔除)

| 不是谁 | 为什么 |
|-------|-------|
| 100 万粉以上大号 | 已有专业团队 + 自有数据,选题成本不在这一环 |
| 真·新人(0 粉) | 自己还没有任何作品作参照——产品的"对比 TA 平时水平"对他们失效 |
| 商业广告主 | 选题逻辑是"赞助什么内容",不是"我自己拍什么"——不在产品范围 |
| 严肃媒体 | 选题逻辑是"事件 + 责任",不是"爆款数据" |

## 价值主张(给用户讲的版本)

### 一句话

**「让你每天少花 30 分钟刷热搜,3 张选题卡告诉你今天该拍啥。」**

### 三个核心价值

#### 1. 决策效率

人工选题 = 刷抖音热搜 30 分钟 + 刷小红书 30 分钟 + 在脑子里比对自己赛道 ≈ 1 小时
本产品 = 输入关键词 + 等 30 秒 = **1.5 分钟**
→ **每天省 ~1 小时。一年 = 365 小时 ≈ 45 个工作日**

#### 2. 跨平台视野

人工 = 主刷自己平台,看不到别的平台风向
产品 = 一次同步看抖音 / 小红书 / 快手三家
→ **抓得到"X 在抖音火了 1 周但小红书还没火"的迁移机会**

#### 3. 按 TA 自己规模衡量

人工 = "1 万赞算爆款"——大号才用得起的标准
产品 = 比的是"这条比你自己**平时 75% 的作品**好不好"——你的"爆款"标准是 TA 自己
→ **小账号也能感知到"我今天的选题是我级别的爆款"**

## 商业模式 / 收费

### 当前定价(以代码为准,见 `server/routers/credits.ts`)

**计费单位是"积分"**,单次预测消耗:
- 基础 **20 积分**(`BASE_ANALYSIS_COST`)
- 每多 1 个平台 +10 积分(`EXTRA_PLATFORM_COST`)
- 典型一次预测 = 30–50 积分

**新用户赠送**:注册即送 **60 积分**(够 1–2 次完整预测,完成 Aha moment)

#### 月费会员

| 套餐 | 月付 | 连续包月 | 年付 | 含积分/月 | 单次预测均价 |
|------|------|---------|------|---------|-----------|
| **Plus** | ¥19 | ¥15 | ¥108(¥9/月) | 200 积分 | ¥1.9–3.8 / 次 |
| **Pro** | ¥49 | ¥39 | ¥300(¥25/月) | 600 积分 | ¥1.6–3.2 / 次 |

#### 积分包(单次按需购买)

| 包 | 价格 | 单价 |
|---|------|----|
| 100 积分 | ¥12 | ¥6.0 / 次预测 |
| 300 积分 | ¥30 | ¥5.0 / 次预测 |
| 800 积分 | ¥70 | ¥4.4 / 次预测 |
| 2000 积分 | ¥150 | ¥3.8 / 次预测 |

> 真值同步规则:**这张表的真值在代码里,文档跟着代码走**。
> 改价改 `server/routers/credits.ts` 的 `SUBSCRIPTION_PLANS` / `CREDIT_PACKAGES`。

### 定价逻辑(为什么是这个数)

| 心理锚点 | 我们的价格 | 对比 |
|---------|----------|----|
| 一杯星巴克 = ¥40 | Plus 月付 ¥19 | 半杯星巴克 / 月,几乎无心理门槛 |
| 一顿外卖 = ¥30–50 | Pro 月付 ¥49 | 一顿外卖 / 月,**主营收套餐** |
| 第三方数据工具 = ¥500+/月 | Pro ¥49 | 1/10 价格 |
| 通用 AI 订阅 = ¥150+/月 | Pro ¥49 | 1/3 价格 |

#### 为什么 Plus 这么便宜(¥19)

- Plus 是**引流款**——不指望它赚钱,赚的是把人留下
- 月付 ¥19 → 月毛利薄(典型 ¥3–8)→ 但 LTV 是 Pro 转化的来源
- 连包优惠 ¥15(-21%)+ 年付 ¥108(等价 ¥9/月,-53%)= 拉长留存,把 Plus 用户钉在产品里

#### 为什么 Pro 是 ¥49

- 600 积分 vs Plus 200 积分 = 3 倍量,但价格只 2.6 倍 → 升级有诱惑力
- 月毛利估 ¥10–25(看用量),**这才是赚钱的套餐**
- 年付 ¥300(¥25/月)= 一次锁 1 年的现金流,降低流失

#### 为什么不更贵

- **腰部及以下创作者价格敏感**——超过 ¥99 流失明显
- 第三方数据工具 ¥500+ 是 MCN 价位,不是我们用户

### 收入预期(简版,数字不可发外)

| 假设 | 数值 |
|------|------|
| 上线半年付费用户 | 500(Plus 350 + Pro 150) |
| 月营收 | 350×¥17 + 150×¥45 ≈ **¥12,700**(连包均价) |
| 上线 1 年付费用户 | 2,500(Plus 1500 + Pro 1000) |
| 月营收(1 年) | 1500×¥17 + 1000×¥45 ≈ **¥70,500** |
| Plus 月毛利估 | ~¥5(用量约 5 次/月) |
| Pro 月毛利估 | ~¥18(用量约 10 次/月) |

> **月营收对比上一版**:之前算的 ¥49,500(假设全 ¥99/月)→ 真实 ¥12,700,**差 4 倍**。
> 这是真实定价决定的——靠走量、走 Pro 升级和年付,不靠单价。

## 竞品对比

| 类型 | 代表 | 优势 | 劣势(我们的机会) |
|------|------|------|----------------|
| **平台自有创作中心** | 抖音创作者服务中心 / 小红书蒲公英 | 免费、平台权威 | 只有自家平台、不主动给选题、看的是已有数据不预测 |
| **第三方数据工具** | 新榜、飞瓜、千瓜、卡思 | 数据全 | **只给数据不给决策**、贵(单平台月费 ¥500+)、面向 MCN 不友好小创作者 |
| **AI 通用工具** | ChatGPT / 文心一言 + 提示词 | 通用强大 | **不接平台真实数据**,生成的选题是 AI 凭印象编的 |
| **小工具** | 各种"灵感工具""选题助手" | 价格便宜 | 数据浅、AI 能力弱、产品体验粗糙 |

### 我们的差异化

```
        高决策力
          ↑
          │
   本产品 ●     ● 第三方数据工具(贵 + MCN 化)
          │
          │ 平台创作中心 ● ●  ChatGPT 通用
          │   (免费但不给选题)
          │
          ─────────────────→
                      数据真实性
```

四象限里**右上角("数据真实 + 高决策力")基本空白**——这是产品的位置:

- 比平台自有 → **跨平台 + 主动给选题**
- 比第三方数据工具 → **AI 决策 + 小创作者价格**
- 比 AI 通用工具 → **基于真实平台数据**

> **平台自己下场做的应对:**
> 1. **跨平台**护城河——平台自己不会做"推荐去别的平台拍",这违反平台利益
> 2. **小创作者友好**——平台优先服务大 V 和广告主
> 3. 一种可能:平台收购我们,而不是自己做(在线工具行业的惯例)
>
> 这是真实风险,记入 [风险登记册](风险登记册.md)。

## 增长策略(简版)

### 主获客渠道(优先级排序)

1. **创作者社群 / 工作室渠道**:腰部以下创作者聚集地,口碑传播
2. **小红书 / 抖音的工具类内容**:产品自己讲产品(meta 但有效)
3. **MCN 公司 BD**:Pro 年付批量授权(¥300/年/席位 × N 人)
4. **SEO**:"选题工具""短视频选题" 等长尾词

### 不优先的渠道

- 信息流广告(获客成本高 + 投放门槛)
- 公众号软文(成本高 + 用户决策路径长)
- 直接 to 企业(企业销售周期长,腰部创作者决策快)

> **关键产品配套**:免费档要做得好用到能转化——
> 不是"功能阉割版",而是"完整体验 + 量受限"。
